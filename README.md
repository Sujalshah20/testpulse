## 📖 About TestPulse

**TestPulse** is a modern, full-stack **Online Examination Processing Platform** designed to simplify the way educators create, manage, and evaluate exams while giving students a smooth and reliable test-taking experience. From auto-grading to real-time analytics, TestPulse handles it all in one place.

> 💡 *"Conduct exams with confidence — fast, secure, and smart."*

## 🚀 Getting Started

TestPulse has two parts — **Frontend** and **Backend**. Both need to be running at the same time for the website to work properly.

### ✅ Prerequisites

Make sure you have these installed on your system:

```bash
node    >= 18.0.0
npm     >= 9.0.0
git     >= 2.0.0
mongodb >= 6.0   (or MongoDB Atlas account)
